# HTTP evidence to capture
1. Open the university portal in Chrome or Edge DevTools → Network.
2. Enable Protocol and capture the first uncached load; note h1/h2/h3, request count and waterfall.
3. Repeat with cache enabled and capture the cached load.
4. If testing a local demo site, save the exact URL and browser version.
5. Do not claim HTTP/3 or a timing unless the browser actually reports it. Place screenshots here.
